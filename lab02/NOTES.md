### Рабочая папка, индекс и коммит
Рабочая папка - директория на компьютере для хранения и изменения файлов проекта.
Индекс - промежуточная область для добавленных файлов перед созданием коммита.
Коммит - зафиксированное состояние файлов проекта в истории Git.

### Отличие Git от GitHub
Git - консольная система контроля версий для отслеживания изменений локально.
GitHub - облачный сервис для хостинга репозиториев и совместной работы.

### Состояния для команд diff
git diff - сравнивает измененные файлы в рабочей папке с индексом.
git diff --staged - сравнивает файлы в индексе с последним коммитом.

### Использованные команды
git status - показывает состояние файлов: измененные, проиндексированные, неотслеживаемые.
git diff - показывает непроиндексированные изменения.
git diff --staged - показывает проиндексированные изменения.
