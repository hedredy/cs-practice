### Сравнение версий и поиск изменений
git diff - показывает разницу между конкретными состояниями (рабочей папкой, индексом или коммитами).
git show - выводит подробную информацию об одном конкретном коммите и изменениях в нем.
git log - показывает общую историю коммитов (хэши, авторов, сообщения).
log -S"def" - нашел все коммиты, в которых добавлялась или удалялась строка, содержащая текст "def".
git blame - показал построчно, кто, когда и в каком коммите написал каждую строку файла.

### Восстановление файла (git restore)
git restore (без параметров) - восстанавливает файл до состояния последнего коммита, безвозвратно стирая текущие несохраненные правки.
git restore --source=... - копирует старую версию файла из указанного коммита (например, HEAD~2) в рабочую папку, затирая текущую.
